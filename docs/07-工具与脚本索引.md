## 一、脚本清单

| 脚本 | 用途 | 典型调用 |
| --- | --- | --- |
| build.ps1 | 一键构建/测试/静态检查/运行/verify/前端构建；web/dist 缺失时自动兜底占位页保证 go:embed 可编译 | `powershell -ExecutionPolicy Bypass -File scripts/build.ps1 [build\|test\|vet\|run\|verify\|web]` |
| check-competitor-words.ps1 | 本地竞品词扫描，与 CI competitor-words job 同逻辑；清单含未跟踪文件（防「本地通过、CI 失败」假阴性） | 提交前必跑：`powershell -ExecutionPolicy Bypass -File scripts/check-competitor-words.ps1` |
| migrate-drill.ps1 | M4 本地迁移演练编排：解压最新备份 → 2 遍（清库 → migrate → 3200 端口隔离冒烟）→ 报告/令牌清单 diff 确定性 | `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\migrate-drill.ps1 [-BackupDir <目录>] [-OutDir <目录>] [-Port 3200]` |
| e2e-run.ps1 | 启动隔离 e2e 环境（3100 端口、独立库 bin/e2e-data/e2e.db，root 账号内置），不碰既有数据 | `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\e2e-run.ps1` |
| e2e-smoke.ps1 | 隔离环境 22 项业务链路冒烟（注册/登录/2FA 二段式/兑换码/log mine 白名单/epay 手工签名回调/入账/返利/订单状态） | 先起 e2e-run.ps1，再跑 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\e2e-smoke.ps1` |
| deploy-smoke-server.sh | 服务器部署冒烟 7 项（/health、schema、RSS 基线、迁移令牌 /v1/models、真实转发计费复核、journald 错误关键字、双进程内存） | 服务器上：`HUI_BASE=http://127.0.0.1:3100 bash ~/hui-api/bin/deploy-smoke-server.sh <tokens.tsv> [expect_schema]` |

## 二、使用约定

- PS 脚本一律 PowerShell 5.1 兼容，含中文注释必须 UTF-8 BOM；bash 脚本 LF 行尾。
- 脚本不得写死密钥/令牌；敏感输入（tokens.tsv 等）退出即删，产物只落 %TEMP% 或服务器 logs/（不入库）。
- 端口隔离惯例：演练/冒烟一律用独立数据目录与非生产端口（本地 3100/3200，服务器旁路 127.0.0.1:3100）；
  触碰生产旧库或生产服务前必须逐次经用户确认（AGENTS.md 第 7 节）。
- 新增脚本：登记本文第一节表格 + `AGENTS.md` §2.3 索引行；删除脚本同步注销两处。
- 脚本行为变化（参数/端口/产物位置）须同步本文并在 CHANGELOG [Unreleased] 登记。
