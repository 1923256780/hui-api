# MAINTENANCE.md — 会话收尾检查清单

> 每次会话（AI 或人类）结束前，逐项自查以下 6 项。**任何一项为「是」都必须在本次会话内完成对应文档更新，没更新文档不算完成。**

## 6 项检查清单

### 1. 结构：目录/模块边界变了吗？
- 新增/删除/移动了目录或包？
- → 是：同步 `docs/01-架构总览.md`（目录结构与设计点），并在 `docs/decisions/` 新增 ADR（用 `_template.md`）。

### 2. 命令：构建/测试/运行方式变了吗？
- 新增依赖、脚本、参数、Makefile 目标？
- → 是：同步 `AGENTS.md` §5 命令速查与 `docs/02-环境搭建与命令.md`；新增/删除/修改脚本时同步 `docs/07-工具与脚本索引.md` 与 `AGENTS.md` §2.3。

### 3. schema：表结构变了吗？
- 新表、新列、索引、迁移脚本？
- → 是：同步 `docs/03-数据模型与迁移.md`（六表概览与落地状态），确认迁移脚本符合其第四节规则。

### 4. 踩坑：本次会话踩坑了吗？
- 排查超过 15 分钟的问题、反直觉的行为？
- → 是：追加 `docs/11-踩坑记录.md`，格式见其条目模板。

### 5. 未决问题：有遗留吗？
- 没做完的子任务、待确认的决策、已知但未修的缺陷？
- → 是：写入 `docs/10-里程碑与进度.md` 的「当前状态」块（风险与未决栏）。

### 6. 文档失真：文档还符合代码事实吗？
- 抽查本次改动涉及的文档段落，确认与代码一致？
- → 不一致：立即修正（以代码为准）；同时检查 `CHANGELOG.md` 的 [Unreleased] 段是否需要补条目。
- → 本次新增/删除/改名的文档与 ADR：必须同步登记/注销进 `AGENTS.md` §2 索引（含一行摘要），否则视为未完成。

## 收尾动作

全部自查后，在 `docs/10-里程碑与进度.md` 的「当前状态」块更新：

- 已完成（本次会话）
- 下一步
- 风险与未决
- 最后更新（日期）

并在「交接记录」追加一条简短交接摘要（2-5 行）。
