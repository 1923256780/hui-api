### 2026-09-03 M2-wave1 收尾（管理面 API 与限流挂接）

- 管理面 API 六组端点 + 会话鉴权 + internal/ratelimit 限流挂接 + 令牌分组接 GroupRatio 全部落地；关键决策沉淀于 ADR 0005（bcrypt 采用 x/crypto 而非自写、HMAC 签名 cookie、auth_version 失效机制、限流与熔断解耦）。
- 交接注意 1（会话与 auth_version，改动必读）：会话 cookie = base64url(payload).base64url(HMAC-SHA256)；payload 含 uid/authv/exp，**auth_version 在中间件层与库比对**（不在签名层）——改密递增 auth_version 后旧 cookie 签名仍合法但比对失败 401；SESSION_SECRET 缺省随机生成（重启全端会话失效），生产在配置文件固定；root 引导幂等（已存在任何 root 则跳过）。
- 交接注意 2（整对象幂等写）：管理面 PUT 一律全量覆盖（显式字段含零值生效，防裸对象丢 priority/weight）；缺省归一化规则——status 0→启用、token.expired_time 0→永久、group 空→default、user.role 0→普通用户；channel.key 空=保留旧值（唯一例外，避免 PUT 回显脱敏值覆盖明文）；token 的 key/key_hash/user_id、root 自身的 role/status（防自锁）不可经 PUT 修改。
- 交接注意 3（写后失效挂接点）：渠道增删改后 `gw.Breaker().Reset(id)`（渠道调度无缓存，失效语义即复位熔断计数）；令牌增删改后 `gw.Auth().Invalidate(keyHash)`（鉴权缓存对 invalid 结果也缓存，必须显式失效）；删除用户级联删令牌并逐个失效——两处挂接共享同一 Gateway 实例（main 装配保证），**测试验证失效行为必须用 h.gw.Auth() 同一实例，独立 NewTokenAuth 实例缓存隔离测不出挂接缺失**。
- 交接注意 4（限流语义）：身份键——全局 "g"、分组 "grp:<组名>"（均拼 ClientIP），令牌 "tok:<id>"；分组配置覆盖全局且共用周期；**被拒请求不记录不消耗配额**；RecordSuccess 与 AllowRequest 分离（SuccessCount 语义）；429 响应带 Retry-After；本机限流 429 不计入上游熔断失败计数（避免自家限流触发上游熔断）。
- 交接注意 5（options 热更与测试纪律）：/api/option PUT 键白名单（relay.*/billing_setting.* 前缀 + ModelRatio/CompletionRatio/GroupRatio/ModelRequestRateLimit* 五精确键）任一非法整体拒绝，写后 Runtime.Reload() version+1；管理面改动必须跑 `go test ./... -race`；凡断言「写后生效」的测试须断言 Runtime.Version() 递增，防只验证内存值未验证热更链路。

### 2026-09-02 M1-wave3 收尾（M1 里程碑完成）

- 计费内核三模式 + 结算挂接 + 内置价单 + 异步日志 + 黄金测试集全部落地；关键决策沉淀于 ADR 0004（expr 选型、计费口径唯一化、tier 单层语义、未配价 503）。
- 交接注意 1（计费口径，改动必读）：tiered_expr 变量为原始 tokens 数——p=纯输入（input−cache_read）、c=输出、cr=缓存读；系数为每百万 tokens 美元价；表达式值单位 micro-USD；quota = round(值 × 500000 / 1e6)。tiered_expr 不叠乘 group_ratio（表达式即终价）；classic_ratio 与 per_call 叠乘 group_ratio。任何计费改动必须全量跑黄金测试集（`go test ./internal/billing/ -run TestGolden`）。
- 交接注意 2（配置键与查找顺序）：options 键 `billing_setting.billing_mode` / `billing_setting.billing_expr` / `billing_setting.billing_price` + `ModelRatio` / `CompletionRatio` / `GroupRatio`（classic 回退价与组倍率）；LookupPrice 顺序「显式声明 > ModelRatio 隐式 classic > 内置 prices.json > ErrUnpriced」。GroupRatio 语义：组名→值；请求组未配置时回退 default 组值，再回退 1.0。
- 交接注意 3（挂接点）：gateway.Serve 中 Freeze 在转发前（余额不足 403 insufficient_quota，无副作用）；Respond 成功后 Settle 多退少补（补扣允许透支到负数，负数余额拒绝后续请求）；转发失败/流中断 RefundFull + 日志标记 aborted；usage 缺失但有正常内容 → 请求体字节/4 粗估 + estimated 标记；unlimited 令牌 Freeze/Settle/RefundFull 全跳过（日志照记实结 quota，detail.Unlimited=true）。
- 交接注意 4（异步日志）：logs 表写入走 AsyncLogWriter（有界 channel 非阻塞 Submit，队列满丢弃并计数）；停机必须调 `Gateway.Close()` 排空日志（main 已 defer gw.Close()）；测试中先 g.Close() 再查库（billing_test helper logRowsAfterClose）。logs.detail 与 Request/Token 字段强类型，不混用字符串拼 JSON。
- 交接注意 5（热更）：管理面写 options 后调用 `config.Runtime.Reload()` 即热生效——billing settingsCache 按 Runtime 版本号失效重建，表达式编译缓存按表达式文本缓存跨热更复用；prices.json 校验含零用量试求值，新增表达式能力（如多层 tier）必须同步该校验。
