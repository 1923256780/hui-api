# docs/INDEX.md — 文档地图

> 本文件是 docs/ 的唯一入口。新文档必须在此登记，否则视为不存在。

## 冷启动阅读顺序

任何会话（AI 或人类）按以下顺序阅读：

1. `AGENTS.md` — 协作规范、禁区、DoD（必读）
2. `docs/INDEX.md`（本文件）— 知道有哪些文档、何时读哪篇
3. `docs/10-里程碑与进度.md` — 「当前状态」交接块，明确已完成/进行中/下一步
4. 按当前任务读对应主题文档（见下表）

## 维护规则

- 新增主题文档：编号顺延（07、08、09…），并在本表登记一行。
- 文档内容与代码事实冲突时，以代码为准，并立即修正文档（见 MAINTENANCE.md 第 6 项）。
- 结构性改动必须同步 01-架构总览.md 并在 decisions/ 新增 ADR。
