## 2026-09-02 winget 安装 Go 网络失败

- **现象**：`winget install GoLang.Go` 报 `InternetOpenUrl() failed 0x80072f19`，go.dev 直连下载 MSI 失败。
- **根因**：网络环境下 go.dev 直连不可达。
- **修复**：改用免管理员 zip 方案，从 golang.google.cn 镜像下载 `windows-amd64.zip`，解压到 `D:\EngineeringFiles\tools\go\`，用 `[Environment]::SetEnvironmentVariable(...,'User')` 追加用户 PATH。
- **教训**：winget 下载失败别反复重试，直接切镜像 zip 方案；用户 PATH 写入优先用 .NET API（等效 setx 但无 1024 字符截断风险）。
